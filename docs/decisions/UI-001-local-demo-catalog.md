# UI-001: on-demand local sample catalog

The owner requested the seven real clips already inspected to be available from
the demo UI. The app stores only metadata and source checksums in Git. It uses
verified local artifacts when present and downloads a selected original on demand
otherwise. Running AERIS creates a new immutable local result rather than
presenting saved outputs as a current run. The UI gives the two bird false positives
and the distant aircraft miss equal visibility with successful examples.

This expands the original one-recorded-sample UI-001 budget at the owner's request.
No media is committed, there is no dataset acquisition or training, and each
source stays below the task's 35 MB per-source bound. The app is a local desktop
demonstration; public hosting and publication of derived videos are separate work.
