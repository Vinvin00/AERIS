How it works

03

Honest by design

What this demo does and does not claim.

!

Not a benchmark

Samples are unannotated smoke runs. They show the pipeline working, not how accurate it is.

!

Accuracy stays blank

Precision, recall and tracking scores need hand-labelled ground truth. Without it they are reported as unavailable, with the reason.

!

Observation only

No targeting, weapons integration or control outputs exist in this project. Everything here is for review.

Plain-English glossary
Detection
A box around something the model thinks is an aircraft in one frame.
Track
The same aircraft followed across frames. Tracks start tentative and become confirmed after repeated sightings.
Forecast
A short, constant-velocity guess of where a track moves next, in image pixels.
Pixel space
All positions are image coordinates, not real-world distances. There is no camera calibration.
